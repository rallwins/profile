# Allwins Rajaiah — technology leadership profile

A static Next.js profile for Allwins Rajaiah, AI Solutions Architect. Content comes from the supplied résumé. Facts the résumé does not state are not added.

## Run

```bash
npm install
npm run dev
```

The dev server uses port **4320**. Open [http://127.0.0.1:4320](http://127.0.0.1:4320).

## Check

```bash
npm run lint
npm test
npm run build
```

Publish an updated résumé with `npm run resume -- <path to the original PDF>`. It removes the email, phone and city, keeps the LinkedIn link, and writes `public/resume.pdf`.

## Deploy

See [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md). The canonical host is `https://allwinsrajaiah.com` on Vercel. Design, architecture, and content rules are in `docs/`.
