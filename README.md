# Allwins Rajaiah — technology leadership profile

A static Next.js profile for Allwins Rajaiah, Solutions Architect and Director of Technology. Content comes from the supplied résumé and the written brief. Unknown facts stay marked TODO.

## Run

```bash
npm install
npm run dev
```

The dev server uses port **4320**. Open [http://127.0.0.1:4320](http://127.0.0.1:4320).

## Check

```bash
npm run lint
npm test
npm run build
```

Regenerate the résumé PDF from the same facts with `npm run resume`.

## Deploy

See [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md). The canonical host is `https://allwinsrajaiah.com` on Vercel. Design, architecture, and content rules are in `docs/`.
